A little help
with your library.

Rillora is still in development. This page covers the current connection and playback workflow.

Get started

  1. Use the included synthetic demo to explore the library and guide.
  2. Add an M3U playlist URL or an Xtream service address with credentials from a provider you are authorized to use.
  3. Add an optional XMLTV guide URL to the same connection. Load the guide, choose a programme, then watch the matching channel live.

Import a playlist file

On Mac, iPhone or iPad, choose M3U file when adding a connection and select your channel-list file. Imports accept absolute HTTP/HTTPS media links, up to 64 MB and 200,000 entries. Direct local video files and HLS stream manifests are not channel-list imports.

The app saves an encrypted snapshot without keeping the original path. To refresh it, use Edit connection and select the updated file. Moving the original does not update the snapshot. Reimport preserves the connection and saved library references; changing a media URL changes that entry's identifier.

File contents stay on each device. A synced connection needs the matching import on each Mac, iPhone or iPad. Apple TV uses hosted M3U URL connections. Mobile document-provider and physical-device import checks are still part of release verification.

A connection will not load

Check the address, account status and credentials with your provider. If a connection appears from another device, it may need credentials and a catalog refresh on this device. Guide playback matches provider EPG IDs first; ambiguous names do not automatically tune a channel.

A video will not play

Check your network and try refreshing the connection. Current development playback uses formats supported by the platform's native player. Broader codec and custom-header support are still being verified. A successful connection does not guarantee that every media format will play.

Across your devices

Optional private iCloud library sync is being verified before launch. It is not yet a verified production capability. Credentials stay local by default; the credential-sync setting is a separate opt-in.

Report a problem

Include the device model, OS version, app version and a short sequence of steps. Use synthetic examples when possible. Do not post passwords, usernames, complete provider URLs, private catalogs or unredacted logs. Reports on GitHub are public.

Open a support report

For privacy questions, use the same support channel and describe the question without including private account information.
