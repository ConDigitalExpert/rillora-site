# Rillora public support site

Public information only. The app's implementation and release checks live in a separate private repository. App Store availability remains pending.

Preview with `python3 -m http.server 9198` and validate with `python3 scripts/check_site.py`.

Use `codex/` branches and pull requests. Publish only material safe for public disclosure. Recheck the privacy page against the final signed app and all embedded SDKs before App Store submission.
