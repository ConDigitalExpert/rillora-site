Privacy

Your information
and Rillora.

Updated October 9, 2026. This describes the current development design. The final signed app and any additional playback libraries will be reviewed before an App Store release.

Information kept on your device

Rillora saves connection information, cached catalog metadata, favorites, watch progress, bookmarks, category choices and playback preferences. Its local repository encrypts saved connection and library data; connection secrets use the platform Keychain. These safeguards do not replace the security of your device or provider.

Connections to your sources

The app contacts the media, artwork and programme-guide endpoints you configure. Your provider can receive your IP address and information needed to service requests, including credentials where required. Those services have their own privacy practices. HTTP connections do not provide transport encryption; prefer HTTPS where your provider supports it.

Optional iCloud sync

When available and enabled, private CloudKit sync sends library changes to your Apple iCloud account using encrypted record payloads. Connection credentials remain local unless you separately opt into syncing them. Provider catalogs are cached on each device. Sync is still undergoing release verification.

Advertising and analytics

The current app has no advertising, analytics SDK or developer-run account service. Rillora's developer does not operate a server receiving your media library or credentials. Any additional SDK's data practices must be reviewed before it is included in a release; the App Store privacy disclosure will be checked against the actual shipped app.

Removing information

Removing a connection deletes its local credentials and cached catalog and marks associated library entries for deletion. If sync is enabled, deletion changes are sent when sync can connect. Turning sync off does not itself erase information already stored in iCloud. Removing the app is not a promise that every Keychain or iCloud record is removed.

This support website

This site uses no advertising scripts, analytics scripts or embedded third-party media. GitHub Pages hosts it and logs visitor IP addresses for security, as described in GitHub's hosting documentation and GitHub's Privacy Statement.

If you choose to submit a support issue, GitHub handles the account and submitted information under its policies. Issues are public; do not include sensitive connection information.

Questions and changes

Contact the Rillora development team through the support page. This page will be updated when release features or data practices change. It does not substitute for the final App Store privacy disclosure.
